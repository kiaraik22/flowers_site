Данный сайт разработан для заказа и доставки комнатных растений!
Он подходит людям,который не могут уделить достаточно времени походам по магазинам,а так же тем,
кто не может в целости довезти свой цветочек до дома и бояться его повредить.





Для того,чтоб запустить сайт необходимо выполнить порядок действий:

1. Установить виртуальное окружение. Команда python -m venv .venv   
2. установить все зависимости из файла requirements.txt
3. Сделать миграции
4. Запустить сайт командой python manage.py runserver
